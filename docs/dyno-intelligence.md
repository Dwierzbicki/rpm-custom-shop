# RPM Dyno Intelligence — measured data foundation
Existing admin records, publication consent, exact SKU validation and chart images remain in place. Optional conditions and measurement points are saved in the existing JSON record; no schema migration or new service is needed. Old records remain compatible.
CSV: exactly rpm,power_ps,torque_nm, comma or semicolon, decimal comma only with semicolon. One ascending run, 2–400 points, same power/torque measurement basis. Manual transcription is explicitly labelled. Unknown values stay unknown.
Metrics use sample maxima, exact samples at 3000/4000 RPM or linear interpolation only between points at most 500 RPM apart. No extrapolation, smoothing or synthetic predictions. A power/torque/RPM relation check flags discrepancies (5% or 10 PS tolerance), not a certification. Operator confirms data, permissions and publication; replacing chart clears points. A manually entered boost maximum does not imply full boost RPM.
Future: AI image/PDF extraction as a reviewable draft, with source coordinates, units, uncertainty and approval. Do not send customer PII or confidential images to an external provider without consent. Comparison/recommendation across runs requires matching measurement basis, conditions, engine geometry, fuel and component identity. No AI API or automatic publication is enabled.
