# Research Center — operator-assisted V1
Admin Power Guides / Technical Research. Choose an engine, topic, public sources, open source-specific searches, copy a structured prompt into an external research tool, paste JSON and preview before importing. Sources include Turbo Familia Crew (specific Facebook profile, not automatic Facebook access). No paid AI API, web scraping, stored credentials or production migrations. Public posts or explicitly authorized materials only. No unverified data attributed to inaccessible pages.
Import is admin protected by existing middleware; same-origin JSON POST, maximum 25 rows / 120k characters; server validates source and current engine version, strips approval fields, preserves null power/torque targets. Same normalized source URL + engine + variant + configuration deduped against existing records, hash ID and insert conflict guard; semantic duplicates across different URLs/labels still require review. Imported records are private drafts; no storefront integration. Existing list may require explicit refresh. Future automatic research needs provider configuration, cost caps, consent, and source verification.

## AI integration (off by default)
Server-only Render variables: OPENAI_API_KEY, RPM_RESEARCH_AI_ENABLED=1, RPM_RESEARCH_DAILY_LIMIT (1–5), RPM_RESEARCH_MONTHLY_LIMIT (1–50, >= daily), optional RPM_RESEARCH_MODEL (default gpt-5-mini). No live provider call until explicitly activated; billing is separate from ChatGPT. Suggested pilot 1/day, 10/month. These are attempt limits, not fixed currency caps. Use a separate API project with billing controls. Atomic UTC counters reserved before request; no retry; 75s timeout; 3 tool calls, 6000 output tokens. Source metadata matching does not verify each claim. No automatic import/approval. UI groups manual import, sources and limits in collapsible panels. No production migration or service creation. API integration not live-tested. Docs: https://developers.openai.com/api/docs/guides/tools-web-search
